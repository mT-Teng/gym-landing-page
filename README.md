# Hadeed Gym: Landing Page

A responsive Arabic (RTL) landing page for a fitness club, built as a personal portfolio project.

**Live demo:** https://mt-teng.github.io/gym-landing-page/

## Features

- Hero section with **today's classes**, calculated from the visitor's clock (live, next, and finished sessions).
- Weekly class schedule with day buttons.
- Membership plans color-coded like weight plates (10 / 20 / 25 kg).
- FAQ section and a booking form with client-side validation.
- Fully responsive, keyboard accessible, and respects reduced-motion settings.

## Built with

HTML, CSS, and vanilla JavaScript (no frameworks).

## Notes

This is a demo project. The booking form does not send data anywhere, and the names, prices, and schedule are sample content.
